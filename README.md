# Article Lab

A colourful B2 English study webpage about **a/an**, **the**, and **no article**.

- 63 rules with 252 examples and notes on exceptions
- Searchable rule explorer and presentation mode
- 30 practice questions with explanations
- Printable complete guide and answer key
- Responsive layout with no build step or external dependencies

## Use

Open `index.html` in a browser, or deploy the repository root as a static website. No installation or build command is required.

## Files

- `index.html`: page structure
- `style.css`: responsive styling and print layout
- `data.js`: rules and examples
- `app.js`: navigation, contrasts, quiz and printing

In presentation mode, use the left/right arrow keys to move between rules and Escape to exit.
